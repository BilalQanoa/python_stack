# Flask Counter App 🔢

A simple Flask application that demonstrates how to use **Sessions** to track user activity.

## Features
* **Visit Tracker:** Tracks actual page reloads.
* **Custom Counter:** A counter that can be manipulated by the user.
* **Bonus - Plus 2:** Increments the counter by 2.
* **Bonus - Custom Input:** Users can specify their own increment value.
* **Bonus - Reset & Destroy:** Options to reset the counter or clear the entire session.

## How to use
1. Install Flask: `pip install Flask`
2. Run the app: `python server.py`
3. Visit `localhost:5000`
